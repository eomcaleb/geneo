# geneo

A minimal, mobile-friendly view of the genealogy in Genesis 1–5, organized by what each chapter reveals.

- **Genesis 1** – humanity created, male and female
- **Genesis 2** – the first couple
- **Genesis 3** – the fall, the promised seed, Eve named
- **Genesis 4** – Cain's line and Seth's line split
- **Genesis 5** – Adam → Noah with ages and a lifespan timeline

Single static `index.html` with no build step or dependencies, served with GitHub Pages. Pick Gen 1–3, 4 or 5 on the left; people fade in and out on a fixed chart, and branches fold.
